# Pleut pas ?

Est-ce que je peux prendre mon vélo maintenant, et sinon à quelle heure exactement ? Gros verdict OUI / NON selon la pluie sur la durée du trajet, radar animé, prévision fine sur l'heure qui vient et vue de la journée. Lieu configurable, Besançon par défaut.

Vue 3 + TypeScript + Vite + Tailwind, site 100 % statique. Données Open-Meteo, Météo-France (pluie dans l'heure) et RainViewer (radar).

```bash
npm install
npm run dev
```
